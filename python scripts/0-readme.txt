Step 1: Install Required Libraries

Open your Command Prompt or Terminal and run this command to install the required Python packages:






:
pip install torch torchvision transformers pillow

or 


py -m pip install torch torchvision transformers pillow

or

python -m pip install torch torchvision transformers pillow





You paste and run that command inside Command Prompt or PowerShell on Windows.

Here is how to open it:

1
Open Command Prompt

Press the Windows Key on your keyboard, type cmd, and press Enter.
2
Paste and run the install command
